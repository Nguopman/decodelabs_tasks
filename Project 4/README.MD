# Project 4: System Vulnerability Checklist & Hardening Audit 🛡️

**Track:** Junior Analyst // DecodeLabs Industrial Kit (Batch 2026)  
**Phase:** Audited Systems & Blue Team Defensive Architecture

## Overview
Project 4 serves as the capstone assessment for the DecodeLabs Cybersecurity Internship. Grounded in the principle that you cannot defend enterprise infrastructure if you cannot secure your own perimeter, this project executes a comprehensive 4-step security checklist on the primary workstation.

## Checklist Modules Audited
1. **Identity Front Door:** Evaluating password policies against NIST 800-63B standards and eliminating unneeded privileges.
2. **Software Decay & Patch Management:** Mitigating software decay by auditing out-of-date packages and security advisories.
3. **Auditing the Human Perimeter:** Disabling guest accounts, eliminating privilege creep, and checking local hygiene.
4. **Network and Endpoint Hygiene:** Enforcing inbound host firewall rules (`ufw`) and verifying disk integrity.
