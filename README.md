# DecodeLabs Cybersecurity Internship — Industrial Training Kit (Batch 2026)

Welcome to my repository for the **DecodeLabs Cybersecurity Internship Industrial Training Kit (Batch 2026)**.

This repository contains the practical projects I worked on during my internship as a **Junior Cybersecurity Analyst Intern**. The projects focus on building a practical understanding of security concepts through Python, including password security, basic cryptography, and phishing analysis.

## Projects

| Project       | Title                             | What I Worked On                                                                                                                                                                                                               | Directory    |
| ------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| **Project 1** | **Password Strength Checker**     | Built a Python-based password strength checker using validation rules, string analysis, and basic entropy-related checks. The implementation uses Python built-ins and follows an efficient O(n) approach.                     | `Project 1/` |
| **Project 2** | **Basic Encryption & Decryption** | Implemented a simple Caesar Cipher to understand the fundamentals of encryption, decryption, modular arithmetic, and reversible symmetric transformations.                                                                     | `Project 2/` |
| **Project 3** | **Phishing Awareness Analysis**   | Developed a phishing analysis and awareness toolkit covering suspicious email indicators, email header analysis, homoglyph and typosquatting detection, and basic decision-making for identifying potential phishing attempts. | `Project 3/` |

## Technical Stack

* **Programming Language:** Python 3
* **Environments:** Kali Linux, Windows
* **Compatibility:** Cross-platform
* **Focus Areas:** Defensive security, data validation, cryptography fundamentals, phishing analysis, and security triage

## About This Repository

The purpose of this repository is to document my hands-on learning and practical work during the DecodeLabs internship. Rather than focusing only on theory, these projects helped me apply security concepts through small, practical implementations and analysis exercises.

Each project includes its own files and documentation to explain the work and the concepts involved.
